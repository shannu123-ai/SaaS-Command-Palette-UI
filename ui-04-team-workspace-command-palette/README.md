# Team & Workspace Command Palette

## Overview

The Team & Workspace Command Palette is a modern SaaS dashboard for managing teams and workspaces.

Users can quickly access common actions such as inviting members, switching workspaces, creating workspaces, and managing team settings.

## Research

Command palettes are commonly used in modern SaaS applications to provide quick access to actions.

They help users find commands quickly without navigating through many menus.

## Design Patterns

- Dark SaaS dashboard
- Sidebar navigation
- Workspace overview
- Team member cards
- Quick action cards
- Searchable command palette
- Ctrl + K keyboard shortcut
- Responsive design
- Toast notifications

## Features

- Team workspace dashboard
- Team member overview
- Workspace information
- Searchable command palette
- Ctrl + K shortcut
- Escape key to close the palette
- Invite Member action
- Switch Workspace action
- Create Workspace action
- Team Settings action

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Open the project in Visual Studio Code.
2. Open the `ui-04-team-workspace-command-palette` folder.
3. Open `index.html` in a browser.
4. Use the command palette to try the available actions.

## Implementation

HTML was used to create the dashboard structure.

CSS was used for the visual design and responsive layout.

JavaScript was used to make the command palette interactive.

The command palette can be opened using the Search Commands button or Ctrl + K.

## Improvements

This implementation combines team management, workspace information, quick actions, and command search into one dashboard.
